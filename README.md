# Tesla Statistics – Power Query practice site

This folder contains a static website and CSV copies of the data tables.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `tesla-statistics`.
2. Upload `index.html` and the complete `data` folder (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published URL shown in the Pages section.

## Use in Excel
Excel → Data → Get Data → From Web → paste the published page URL.
The HTML tables should appear in Navigator. CSV files are also available under `/data/`.

## Contents
- `index.html`: the website
- `data/*.csv`: individual datasets
